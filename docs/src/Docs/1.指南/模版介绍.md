## 微前端后台模版介绍

该模板使用vue3 + vite作为主应用，分别适配了`vue3+vite` / `vue2+vite` / `vue2+webpack` / `react+vite`子应用，同时各个子应用均测试了`派发组件`/`路由组件`/`跨框架组件`

<small>⚠️: 本项目只`测试`一些第三方库是否`适配`, 不会提供很全的后台功能(github已经有很多优秀的模版了); 如果你的项目想引入微前端, 最好的做法是基于主应用，参考性的将该项目的部分功能移植到你的项目中去而不是直接用这个项目.</small>

## 适配清单

1. 样式: 适配PC端 & 移动端

2. 浏览器：兼容微信浏览器 / Chrome / 手机自带浏览器 (包括iphone/小米/vivo/oppo/真我)

3. 前端框架：兼容vue3/react/vue2

## 模版有哪些特色功能

- 三种跨框架的组件共享方案：`派发组件`、`路由组件`、`fl组件库`

  1. 派发组件`<MicroComponent>`支持主应用`下发组件`给子应用使用, `兼容vue3/vue2/react`, 同时`支持作用域插槽`，常用于业务组件

  2. 路由组件`<MicroApp>`支持组件注册为路由给其它应用使用，常用于较大区域的业务模块

  3. `fl组件库`是我另一个[单独的项目库](https://www.npmjs.com/package/frame-less-ui)，可以在任何前端项目中使用，常用于业务组件
  
- `<ReactComponent>`组件支持在`vue的环境下直接使用React组件`, 包括阿里`低代码渲染器`这样复杂的React组件

- 微前端和低代码`混合开发`, 在代码中使用低代码渲染器渲染低代码页面, 再低代码中可以反向通过\<MicroApp\>加载子应用

## 模版还做了什么?

模版内有个`micro-app-tools子包`，它在micro-app的基础上进行了`二次封装`, 通过提前配置子应用, 减少了大量配置参数及命名唯一性问题。 让用户使用`<MicroApp>`加载子应用最少只需要传入子应用名称`_name`以及目标路径`_path`即可, 同时_path支持动态变化, 页面会自动刷新

```tsx
// eg: 加载子应用appA的/pageA页面
import MicroApp from 'micro-app-tools/vue3/MicroApp';

<MicroApp _name="appA" _path="/appA/#/pageA"/>
```

# frame-less-ui（跨框架组件库）

> <small>项目已开源在https://github.com/LAMMUpro/frame-less-ui.git</small>

## 💡由来

js原生支持web component(自定义组件)，天然跨框架，而vue3支持将vue组件编译成web component

## 使用场景

常用于一些跨框架的业务/复杂组件，例如`成员选择器` / `部门选择器` / `虚拟列表树`，可以在任何前端项目中使用，可以基于element-plus进行二次封装。

## 使用

```TSX
import FlPagingSelectV3 from 'frame-less-ui/vue3/paging-select';

<fl-paging-select-v3
  v-model:value="info.id"
  v-model:label="info.name"
  :api="api"
  immediate
  :optionSetting="{ label: 'name', id: 'id' }"
  style="width: 300px"
>
</fl-paging-select-v3>
```

## 潜在的问题

1. web component使用了shadow dom，不能使用样式穿透来修改组件样式了

2. 针对不同框架需要额外包装一层来解决各框架特定的问题，会造成一些工作量

3. 对web component的开发各方还未处于成熟阶段，某些api/特性可能还不兼容

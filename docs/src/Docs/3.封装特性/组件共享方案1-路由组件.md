# 路由组件

## 💡由来

微前端可以用来加载其它应用的页面。那将组件注册为页面，通过微前端来加载其它项目的组件是否可行呢？
经过测试，答案是可以的

## 使用场景
路由组件建议用在比较复杂的区块组件上（例如业务详情），因为通过微前端加载组件的方式是比较耗时耗资源的

## 用法

```TSX
import MicroApp from 'micro-app-utils/vue3/MicroApp.vue';

// 使用_router-mode="pure"能避免url出现不必要的路由信息
<MicroApp
  _router-mode="pure"
  _name="vue2"
  _path="/vue2/#/ComponentA"
></MicroApp>
```

## 潜在的问题

1. 无限循环嵌套
    
    MicroApp组件默认支持嵌套3层，可以规避无限循环的问题，如果需要嵌套更多层，可以给MicroApp传递_forceInit参数

2. 无法双向绑定

3. 无法调用组件方法
   
    现阶段先避免组件方法这种使用方式

    后续可能会解决这个问题
